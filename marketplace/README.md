# Marketplace preparation

This directory holds the draft listing for OpenSpec BSL Flow.

- `entries/openspec-bsl-flow.json` contains the plugin identity, maintainer, categories and Git source.
- `overview/openspec-bsl-flow.md` matches the root `PLUGIN_OVERVIEW.md`.
- `screenshots/openspec-bsl-flow/` contains the shared images of Changes and Specs taken before the identity change.

The draft pins the fork's `v0.6.2` tag. Before submitting it, verify the public tag and the `openspec-bsl-flow` identity in its manifest. The earlier `v0.6.1` tag identifies `openspec`. See the [release checklist](../docs/RELEASING.md) for validation.
